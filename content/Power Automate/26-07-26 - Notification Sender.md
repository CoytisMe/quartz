## Power Automate notification sender address

Flow run failure/status notifications come from:

`PowerAutomateNoReply@microsoft.com`

Useful if you want to filter, block, or set up a mail rule for these.

## Followup

If flow failure emails are getting noisy, a mail rule filed on this sender could auto-file them into a subfolder rather than blocking outright — keeps a paper trail for debugging without cluttering the inbox.
