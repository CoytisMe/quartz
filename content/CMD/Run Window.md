## What it do
Windows + R opens ‘run’ there’s 1000 things you can do from there but here’s my favourites. You can get 90% of these through hitting start and searching but that search can suck someones and less animation means faster through a remote window.

Hit Control + Shift + Enter if you want to run as administrator, mostly for CMD.

## Basic
- Cmd - Command Prompt
- Appwiz.cpl - Programs and Features, for uninstalling / repairing
- Control Printers - Straight to printer settings
- Control Panel - Guess
- Regedit - Registry Editor
- lusrmgr.msc - User management, mostly for turning off passwords expiring
- devmgmt.msc - Device manager
- eventvwr - Event viewer
- %appdata% - Opens appdata (to roaming for some reason)
- %localappdata% - Opens local appdata
- . (Just a full stop) - Opens the user folder
