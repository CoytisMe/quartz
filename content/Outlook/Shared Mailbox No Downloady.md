## Saves space, Stops PSTs breaking
Some places have hilariously large shared mailbox that are guaranteed to fuck your PST. Set them not to cache

**This setting is per profile, it will need to be set again if you make a new one.**

If they're already downloaded then Outlook is going to freak the fuck out, give it time and it'll sort itself out.

File > Account Settings > Account Settings > Double Click the account > More Settings > Advanced > Uncheck 'Download Shared Folders' > Click OK > Restart Outlook.
